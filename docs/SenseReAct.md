# SenseReAct 框架概述

## 结构

```
SenseReAct
    - 感知层 Sense Layer
        - 环境层 Environment Layer
            1. 外界输入：如摄像头的图像数据、传感器的运动数据、等等。
            2. 传统感知方案：将`外界输入`作为输入，使用传统的计算机视觉方案（如 `yolov5-seg`, `rnn`, ...）对输入进行处理，输出某些结构化的内容。
            3. VLM方案：将`外界输入`与`传统感知方案`的输出作为输入，使用VLM模型（如 'qwen3.5-0.8b-instruct'），生成总的语段形式的描述。
        - 管理层 Information Management Layer
            1. 全局环境管理：负责存储管理从游戏一开始到当前时刻的所有环境信息（如传统感知方案与VLM方案的输入结果）
            2. 局部环境管理：负责存储管理当前时刻往前推一定时间以内的所有环境信息
    - 思考执行层 ReAct Layer
        - 大脑区域
            1. 宏观战略层：负责战略的部署、与队友协调、处理选手发送的提示词等高级任务
            2. 转换层：将宏观战略层的对策部署，转化为一条条可以实际落地的行为
            3. 解析层：将一条条行为，转换为一条条机器人的操控指令
        - 小脑区域
            接收操控指令并操控机器人运动
```

## 补充说明（2026-03-14）

### 1. 事实与语义总结的职责划分

1. 传统感知方案：负责产出事实性结果（结构化内容），作为基础事实来源。
2. VLM方案：
    - 负责补充事实性结果。
    - 负责对传统感知方案与VLM方案这两个单体得出的事实进行语义总结，形成面向推理层可读的语段描述。

### 2. 实时性与异步访问机制

Sense Layer 采用异步运行机制：

1. 后台持续更新：感知链路在后台持续更新内部私有变量。
2. 冻结访问快照：当 ReAct Layer 请求当前环境信息时，Management Mechanism 会冻结该时刻可供访问的公有变量状态。
3. 单次操作一致性：在 ReAct Layer 完成单次操作前，对外可访问状态保持不变，确保同一决策周期内读取到一致环境信息。
4. 操作完成后切换：待本轮 ReAct 操作结束，再将更新后的最新状态切换到对外可访问变量。

### 3. 鲁棒性与降级策略

1. 无论何种情况下，系统都至少可以从传统感知方案中获得基础内容。
2. 若 VLM 方案推理崩溃，则触发模板降级策略：
    - 使用模板填充传统方案产出的内容。
    - 明确标注当前数据状态真实性不稳定。
3. 该策略保证系统在VLM异常时仍能输出可用结果，并向上层显式暴露风险状态。
